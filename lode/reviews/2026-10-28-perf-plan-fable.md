# Review: `docs/PERF-PLAN.md` (Wave P) — `fable`

**Verdict:** Root causes are credible and the lane split is sound. The plan under-specifies the *correctness* side of every fast path it introduces: lazy FP status, dead-flag elimination, in-trampoline chaining with live cached registers, and store-side-table consistency. Each lane needs the checklist items below before the acceptance gate can be trusted.

## 1. Missed bottlenecks and edge cases

- **coremark:** Class B translators pay a 7-instruction Soft-TLB per access where `a32rt` pays one `[x20, w, uxtw]`. Targets are plausible but the plan never states the per-access budget; instrument TLB-miss rate per translator before assuming chaining alone closes the gap. Unaligned `lw`/`ldr` through `LWL/LWR` (MIPS) and misaligned-trap guards (SPARC) are not costed. Shifts of 64-bit guests to 32-bit results (`addiu`/`sllw`) need the sign-extension invariant on `mips64rt`/`rvrt` kept inline.
- **chacha20:** Big-endian guests (`ppc32`, `sparc32/64`) need `rev` on every word load and store; not mentioned. `xor reg,[mem]` and `add [mem],reg` read-modify-write forms on `i686` are not in the P3.1 list. `rvrt` lowers neither `RORI`/`ROR` (Zbb) nor the 4-instruction rotate idiom; check what the toolchain emitted before claiming `chacha20` closure.
- **vfp_simd:** `i686rt` is absent from the FP discussion. If the bench was built `-m32` without `-msse2 -mfpmath=sse`, it runs x87 80-bit code that no lane addresses. State the compile flags in the plan. RISC-V `RMM` (frm=4) has no AArch64 rounding mode and must stay on the helper permanently. `fres`/`frsqrte` (PPC) and `fsqrt` approximations are implementation-defined; keep on the interpreter so `--difftest` stays exact.
- **calls_ibtc:** IBTC keyed on guest PC alone is unsafe across `mmap`/`munmap` of code at the same address; every table (`g_chain`, `ibtc`, `jit_lut`) needs the cache epoch in the tag or a flush coupled to `invalidate_all`. Hash shifts differ per ISA (`>>1` RV-C, `>>2` MIPS/SPARC/PPC/LA64, byte-granular `i686`). RAS on SPARC must survive `SAVE`/`RESTORE` mismatches (`ret`/`retl` target comes from `%i7` of the restored window).
- **syscalls:** Verify the other 8 translators do not also flush on syscall (P1.1 pattern); only `ppc32rt` is audited. The Rosetta 2 figure of `9 us` for `syscalls` cannot be a real `getpid` loop; mark it as non-comparable rather than listing it as a baseline. Guest `rt_sigprocmask`/`sigaltstack` must still force a budget exit so pending signals are not deferred 4,096 blocks.

## 2. Correctness hazards

- **Chaining vs signals:** A signal handler cannot modify the budget register `w22`. The chain stub must `ldr` an `async_pending` word (2 instructions) or the 6-step `tgkill` quiescence has unbounded latency. Chained code with GPRs live in host registers (`mips32rt` `w0–w15`, `sparc64rt` window cache) means the fault/signal handler must map host `mcontext` back to guest state via a per-block register map keyed on host PC. Without it, `siginfo`/`ucontext` and `--difftest` diverge.
- **`--difftest` blind spot:** Disabling chaining under difftest means the smoke gate never executes the chained path. Add a second mode: chain freely, compare at syscall boundaries, and fail on CRC or register divergence.
- **`i686rt` `skip_flags`:** Any instruction that can fault (memory operand, `div`, `int`, `into`) is a flag-observation point: a `SIGSEGV`/`SIGFPE` handler sees `EFLAGS`. The backward scan must stop at every potentially-faulting instruction unless the fault path materializes flags. Readers beyond `jcc`: `setcc`, `cmovcc`, `adc`/`sbb`/`rcl`/`rcr`, `pushf`, `lahf`, `cmc`, `loop*`, `rep` prefixes, `sahf`, `into`.
- **Partial flag writers:** `INC`/`DEC` preserve `CF`; `ROL`/`ROR` write only `CF`/`OF`, and *nothing* when `count & 31 == 0` (likewise `CL`-shifts, `SHLD`/`SHRD`). With a lazy model this forces a `lazy_op` variant that carries the prior `CF`, or materializing before the partial writer. `OF` for rotates with count > 1 is undefined on hardware; the DBT must match the interpreter's choice bit-for-bit or difftest fails.
- **`rvrt` NaN-boxing:** `F` ops must check both operands are boxed (`hi32 == 0xffffffff`) else substitute canonical NaN. Results must be canonical `0x7fc00000`/`0x7ff8...`; AArch64 only does that with `FPCR.DN=1`. `DN=1` is correct for RISC-V but wrong for MIPS/PPC/SPARC/LA64, which propagate payloads. `FLT`/`FLE` signal on quiet NaN (`fcmpe`), `FEQ` does not (`fcmp`). `FCVT.W.S` of NaN yields `0x7fffffff` on RISC-V and `0` on AArch64; `FMIN`/`FMAX` order `-0 < +0` and quiet sNaN. Keep these on explicit sequences, not the generic helper, or `vfp_simd` stays slow.
- **`fflags`/sticky status:** Fast paths that stop reading `FPSR` must not also clear it. Let `FPSR` accumulate natively and fold into `fcsr`/`fpscr`/`fsr` on CSR read, syscall, signal, and block-loop exit. Watch the masks: MIPS `FCSR & 0xFF` includes the sticky flag bits 6:2, so the fast path self-disables after the first inexact op; use `RM | Enables | FS` (`0x100_0F83`). SPARC `cexc` reflects only the *last* op and `fcc` must be set per compare; lazy `cexc` needs a last-op snapshot. PPC `FPRF`/`FI`/`FR` must be recomputed from the last result on `mffs`/`mcrfs`/`Rc=1`.
- **`sparc64rt` PF_X Soft-TLB:** A `has_code` check at fill time goes stale when a block is later translated on that page. `dbt_translate` must evict TLB write tags for the page (or bump a TLB generation) before installing the block, and `mprotect` must flush the TLB. The same ordering applies to `ppc32rt` `code_pages`: set the bit *before* publishing the block, check both pages for stores straddling a 4 KiB boundary (`stw` at `0x...ffe`, `stmw`, `stswi`, `dcbz`), and honor `icbi`/`isync` because PPC guests invalidate via cache ops, not `mprotect`.
- **`mips32rt`/`mips64rt` `sigsetjmp` hoist:** Hoisting means a fault lands at the loop head with cached GPRs discarded; the handler must spill them from `mcontext` first. `sigsetjmp(buf, 0)` leaves `SIGSEGV` blocked after `siglongjmp` unless the handler uses `SA_NODEFER` or unblocks explicitly. The static `t_jmp` breaks under `clone`; make it per-thread. Block truncation (P1.4 style) must never split a branch from its delay slot on MIPS/SPARC. `dbt_u0_prefill` removal leaves the miss trampoline as the only TLB filler; it must be reentrant with cached GPRs live.
- **Cache flush atomicity:** `DBT_MARKS_MAX=4096` and `DBT_CODE_CAP` exhaustion must reset arena, IBTC, chain slots, and `jit_lut` under one epoch bump. Prefer patching data-table slots over patching code so no I-cache maintenance is needed (`A32H_CAP_ICACHE_TRAP_IALLU`).

## 3. Checklist additions per lane

**All lanes:** record `--difftest` with chaining enabled at syscall-boundary compare; add a signal-latency test (`tgkill` into a 10 M-iteration tight loop, assert delivery under 1 ms); add a fault-in-chained-block test that checks `ucontext` GPRs; confirm `FPCR.FZ=0` and per-ISA `FPCR.DN`.

- **P1 (`ppc32rt`/`ppc64rt`):** grep every translator for syscall-path `invalidate_all`. Page-bitmap: set-before-publish, straddle check, `dcbz`/`stmw`/`icbi` paths. FP fast path: `FPRF` lazy recompute test via `mffs`; `fcmpu`/`fcmpo` on NaN; `frsp` double rounding. `ppc64` truncation emits exit to `pc + 4k` and caches `k=0` fallback entries; `lwarx`/`stwcx.` never split across a truncation.
- **P2 (`rvrt`):** boxing check + canonical NaN for every `F` op; `fcmpe` vs `fcmp` split; `FCVT` NaN/overflow saturation table test; `RMM` stays helper; `fflags` fold on `csrr`/`frflags`/syscall; `DIV` by zero and `INT_MIN/-1` guards; `jit_lut` tag includes epoch; `C`-extension 2-byte targets hash with `>>1`.
- **P3 (`i686rt`):** `skip_flags` stops at faulting instructions and the full reader list above; count-zero semantics for `ROL`/`ROR`/`SHLD`/`SHRD`/`CL`-shifts; `INC`/`DEC` `CF` preservation under live lazy op; interpreter-defined `OF`/`AF` matched bit-exact; state the `vfp_simd` FP ABI (x87 vs SSE) and add an x87 item if needed; IBTC tag includes epoch and byte-granular `eip`.
- **P4 (`mips32rt`/`mips64rt`):** per-thread jmp_buf; `SA_NODEFER` or explicit unblock; `mcontext`-to-GPR spill on fault; host-PC-to-block side table; `FCSR` fast-path mask excludes flags 6:2 and includes `FS`; `LWC1` etc. go through the Soft-TLB; no block ends between branch and delay slot; `LWL/LWR`/`LL/SC` remain correct with cached GPRs.
- **P5 (`sparc32rt`/`sparc64rt`):** TLB write-tag eviction on `dbt_translate` and `mprotect`; `cexc` last-op semantics plus `fcc` per compare; `g_chain` slots cleared with epoch; `rev` on all BE loads/stores; `SAVE`/`RESTORE` inline path checks `cansave`/`canrestore`/`otherwin` and traps `window_fill`/`spill` to C; `FBfcc` with annulled delay slots; RAS reads `%i7` after window change.
- **P6 (`loongarch64rt`):** `region_epoch` bumped on every code-page write via the TLB write-gate before `dbt_guest_sum` is removed; `JIRL` with `rd != 0` pushes RAS; `BCEQZ`/`BCNEZ` read `fcc` consistently with the FP emitter; `FLDX`/`FSTX` via Soft-TLB with 8-byte straddle check; `fcsr0` fast-path mask covers `Enables` and `RM` but not the sticky `Flags` field.
