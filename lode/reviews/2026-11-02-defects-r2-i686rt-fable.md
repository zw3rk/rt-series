| I686-R2-1 | Temporary/pinned permissions visible to other threads | **INCOMPLETE** | Pinning is removed; `widen_prot` is now a strict AND. A reader/writer handshake (`s_exec_readers` / `s_subpage_writers`, `vm32.c`) quiesces guest execution around every lock holder, and A2 futex waits moved to a private waiter table so no page stays widened across a blocking wait. Both engines bracket execution with `exec_enter`/`exec_leave`. **Gap:** `i686_vm32_subpage_lock()` clears the caller's own reader registration and `unlock()` never restores it. `dbt_get_or_compile` (A2 path) takes the lock after `exec_enter`, so the first run of every freshly compiled block on A2 executes **unregistered**; a sibling's transient `union_prot` window is then visible to it. ## Section 3: Remaining or Newly Introduced Consequential Findings

1. **[High] R2-4 residual ordering race on A1** — `pre_pgen` is sampled *after* `smc_protect`; a concurrent SMC write-fault in that window unprotects and bumps first, so later stores during translation are undetected and a stale block publishes. Move the sample before `smc_protect` (`src/dbt/engine.c:484-493`).
2. **[Medium] R2-1 residual: lost exec registration after `subpage_lock`** — `i686_vm32_subpage_lock` drops the caller's reader registration and `unlock` does not restore it; the first execution of every newly compiled A2 block runs unquiesced (`src/vm/vm32.c:286-305`, `src/dbt/engine.c:640-657`).
3. **[Medium, PLAUSIBLE] Writer spin can livelock against a chained guest loop** — `subpage_lock` holds the mutex while `sched_yield`-spinning until `s_exec_readers == 0`. If DBT direct chaining keeps a sibling in a guest spin-wait that depends on the lock holder's progress (e.g. producer `read()` staging while the consumer spins on a flag), neither side advances. Not confirmed; depends on whether chained blocks ever return to the dispatcher without a guest syscall/fault.
4. **[Medium] A2 futex semantics narrowed (Linux)** — the private waiter table returns `-ENOSYS` for `FUTEX_WAKE_OP`, all PI ops, and never wakes across processes for shared (non-`PRIVATE`) futexes; a 65th concurrent waiter gets `-ENOMEM`. Previously the kernel served these. Affects 16K/64K-page hosts only.
5. **[Medium] Missing `-Werror`** — see Section 2.
6. **[Low] A2 `sys_read` deviation** — requires the *entire* `count` to be writable up front and `malloc`s `count` bytes; `read(fd, buf, large)` into a smaller buffer returns `-EFAULT` instead of Linux's short read, and a huge `count` triggers a huge allocation (`src/os/syscalls.c:93-117`).
7. **[Low] R2-7 edge** — interior split with the only free slot at a higher index silently drops the suffix and leaks the duplicated fd (`src/vm/vm_file.c:406-432`).
8. **[Low] Interpreter plain loads/stores remain unfenced in TSO mode** (see R2-8 note).

Unverified limits: no Linux/lima execution, no parity suite run, no runtime confirmation that `w12–w14` are free scratch in the string emitter, and no numeric x18 encoding scan.
