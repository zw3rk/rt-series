| M64-R2-1 | Ordinary stores outside the LL/SC critical section | **INCOMPLETE** | **Fixed:** `guest_st8/16/32/64` now wrap `memcpy` + `mem_note_guest_write` in `mips_llsc_write_lock/unlock`; `sc_lock` is recursive via thread-local `g_sc_held` (`unaligned.c:291`), so `do_sc`/`do_scd` hold the lock across check + `guest_st32/64` + epoch bump. Staged copyouts (`l2a_commit_guest_write`, `sc_uname`, `mips_sc_waitid` memsets) write under the lock. Weak no-op fallbacks in `mem.c` keep interp-only links sound. **Not fixed (a):** `guest_range(…, write=1)` (`syscalls.c:156`) now calls `mips_llsc_note_write` at *validation* time and returns a raw pointer; the actual write by the caller (getdents, getrandom, signal-frame build, `clock_nanosleep` remainder, stat family, etc.) happens later, outside `sc_lock`. The audited window (write lands between SC's compare and its commit, SC reports success, value lost) persists for those writers. **Not fixed (b):** DBT ordinary stores are emitted inline (`emit_mem.c` `ei_mem_aligned`/`ei_unaligned`, Soft-TLB miss sites) and never touch `sc_lock` or the epoch; only LL/SC decline to interp (`ei_atomic` returns 1). A DBT thread's plain `SW` to a reserved word during another thread's `do_sc` compare-and-commit is unserialized. Practical exposure is narrow (well-formed lock-free code does not race plain stores against SC on the same word), but the finding's stated requirement, a shared write transaction covering all guest-memory writers, is not met. |

Staging buffers are freed on every exit path (checked all five `free` sites in `mips_sc_vec` and three in `l2a_io_common`); no fd or memory leak. Counts are capped at `L2A_IO_MAX` (Linux `MAX_RW_COUNT`), and `malloc` failure degrades to a 4 KiB short transfer, which is legal. |
| M64-R2-3 | DBT compilation performs faulting speculative fetches | **VERIFIED** | New `dbt_probe_insn` (`dbt.c:412`) is pure: `mips_mem_ok(READ\|EXEC)` + `memcpy` + endian assembly. All three speculative sites (`dbt_compile` main loop and delay-slot fetch, `block_branch_likely`, `trace_block_exit`) use it. On a failed delay-slot probe the branch is dropped from the block (`n--; cur -= 4`), so the interpreter executes branch + slot architecturally. Note: `mips_fetch` itself returns `MIPS_FAULT` without delivering a signal, so the audit's side-effect premise was weaker than stated; the change is still correct and removes the `fetch_covered`/task-size path from compile-time inspection. Minor semantic delta: the probe requires `READ\|EXEC` where `fetch_covered` may differ for exec-only pages; not consequential under Linux MIPS semantics. |
| M64-R2-4 | Fork inherits stale quiescence entries | **VERIFIED** | `mips_threads_atfork_child` (`threads.c:707`) reinitializes `l4b_mu`/`l4b_cv`/`l4b_hmu`, zeroes `l4b_slots`, sets the leader, clears LL state, then calls `mips_qs_atfork_child` and `mips_llsc_atfork_child`. Both fork entry points call it (`sc_fork` in `syscall_min.c:443`, `l4b_clone_fork` in `threads.c:413`). `mips_qs_atfork_child` resets `qs_mu`, `qs_mutating`, all slots, and re-registers the surviving thread in slot 0 as `LIVE` with `leases=1`, `qs_leases=1`, `depth=0`, matching the enclosing `mips_syscall` wrapper's pending `mips_qs_lease_exit` (verified: exit decrements to 0 and takes the non-parked path). `mips_llsc_atfork_child` clears `sc_lock`, `g_sc_held`, and all reservations. | M64-R2-5 | D-format assumes wide `long double` | **VERIFIED** (with one new edge regression, see Section 3) | `fp_adj_d`/`fp_sqrt_adj` removed. ADD/SUB use Knuth TwoSum (`err = (a−a1)+(bb−b1)`) for exact residual sign; MUL uses `fma(ma, mb, −mr)` on `frexp`-scaled mantissas (exact TwoProduct); DIV uses `fma(−mr, mb, ma)` with the remainder of a correctly rounded quotient being exactly representable, sign-corrected for negative divisor; SQRT uses even-exponent scaling and `fma(−mr, mr, ma)`. `fp_round_d` applies directed rounding from `(r_RNE, sign(exact − r))`, which is correct for RZ/RP/RM, and saturates overflow per mode (RZ → ±DBL_MAX, RP → +∞/−DBL_MAX, RM → DBL_MAX/−∞). `−0` on exact cancellation under RM is preserved. | M64-R2-6 | Underflow never raised | **VERIFIED** | `fp_inexact` (S), `fp_round_d` (D), `fp_ps_lane` (PS), and the COP1X MADD family now raise `FP_EXC_U` on tiny inexact results, and on tiny exact results when the U enable bit is set (IEEE trapped-underflow semantics). ## Section 3 — Remaining or Newly Introduced Consequential Findings

1. **M64-R2-1 residual (carry-forward, High → Medium practical).** Two writer classes remain outside the SC critical section: (a) all `guest_range(…, write=1)` consumers, where `mips_llsc_note_write` fires before the write instead of around it (`syscalls.c:156`); (b) DBT inline host stores from `emit_mem.c`. Suggested closure: have `guest_range` writers commit through a lock-holding copy helper like `l2a_commit_guest_write`, and either route DBT stores that hit a page with an active reservation through a slow path, or make `do_sc` perform its compare-and-commit with a host atomic (`CAS` on the host word) so the value check and store are indivisible against inline host stores.

2. **New: spurious overflow flag at the format maximum (Low).** `fp_round_d` (`fp.c:332-335`) raises `O` when `|r| == DBL_MAX` and the residual points away from zero, and `fp_inexact`/`fp_ps_lane` raise `O` whenever `|q| > FLT_MAX`. Under RN and RZ, an exact value in `(MAX, MAX + ½ulp)` rounds to `MAX` with unbounded exponent and IEEE 754 §7.4 signals only inexact. Example: `DBL_MAX + 1.0` or `FLT_MAX + 1.0f` now set `O` where the pre-commit code and QEMU softfloat set only `I`. Value results are unaffected. Will surface as an FCSR mismatch against the oracle in a boundary test.

3. **Unverified lock-ordering and hot-path cost of the global `sc_lock` (informational).** Every interpreter scalar store now takes the process-wide test-and-set `sc_lock` plus `mips_qs_block_preempt` (signal-mask manipulation), and `mem_note_guest_write` → `dbt_invalidate_range`/`vm_pages` now run under that lock. Not measured; per the performance rule this is a hypothesis, not a finding. Recommend a per-phase timer run on an interp-mode multithreaded workload before further work, and a check that nothing reachable from `dbt_invalidate_range` or the host write-gate fault handler can itself call `guest_st*` on another thread while waiting on a DBT lock.

4. **Formal C11 data race on `qs_slot_t.pthread` (Low, residual of M64-R2-8).** Plain `pthread_t` written by `qs_touch` while the slot is `LIVE`, read by `qs_preempt_handler`. Make it `_Atomic` or guard touch under `qs_mu`.

No regressions in previously verified Round-1 remediations were observed in the touched files.
