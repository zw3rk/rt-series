The catalogue exposes a serious coverage gap, but P0 risks replacing misleading smoke results with an impractical universal gate. Across all ten translators, standardize **test contracts and evidence**, while selecting cases by guest ABI, engine, backend, provider, and supported features.

- **CRITICAL — §1–§2: “smoke passed” does not establish guest execution.** Structural checks, file existence, host units, and guest parity are different evidence. Report them separately. `guest-payload` is disconnected from smoke, and `ALL_OK` despite missing required tools is false qualification. Require declared coverage and nonzero execution **per required matrix cell**, not merely aggregate `pass>0`. Fix the nonexistent acceptance path, T5 claims, and `git init -b main` to `master`.

- **HIGH — P0–P2: uniform interfaces do not imply uniform engines or availability.** Establish which translators actually expose each engine and differential mode. Distinguish required, unsupported, infrastructure-missing, and failed cases; unsupported must not become a pass. Thumb is an execution state, SPE a CPU/ABI feature combination: rows need explicit ELF ABI, endianness, CPU model, extensions, libc, and sysroot identity. A musl manifest cannot cover glibc IFUNC tests.

- **HIGH — P0: timeout and oracle contracts are incomplete.** Raising 360 seconds above 480 seconds still ignores aggregate work. Use per-case deadlines, an aggregate budget, process-group cleanup, uniquely named containers, and verified removal. Preserve timeout, crash, mismatch, and infrastructure failure separately. Compare deterministic outputs; normalize addresses and ordering where appropriate. Capture guest signal details inside fixtures, using expected address relationships. QEMU is a comparator, not architectural authority; pin its version and CPU configuration.

- **HIGH — §3/P4: portability requires build and execution adapters.** Select QEMU TCG cases by revision and target requirements; “same sources, every ABI” overstates portability. Standalone Darwin must execute Linux guests through its backend, while a Linux oracle may run separately. `hl` needs its own integration leg. Darwin’s 16 KiB granule exposes permission and mapping problems; it does not alone define Soft-TLB selection or correctness.

- **HIGH — §3: the grind needs semantic expectations.** `stress-ng` class selection is not an exact stressor allowlist; specify individual stressors, verification, resource caps, and unsupported-feature policy. Ten seconds multiplies across stressors, engines, ABIs, and hosts. Equal exit status can mean equal skips. LTP and `libc-test` require kernel-feature expectations and reviewed exceptions, not a frozen QEMU failure set. Darwin backend omissions must remain visible.

- **MEDIUM — §3: compiler and numerical suites need adapters.** GCC torture includes harness directives and target exclusions. Separate compiler-under-translation testing from execution of identical prebuilt binaries. Preserve generator versions, seeds, flags, reproducers, and reduction workflows; account for implementation-defined behavior. TestFloat needs ISA-specific rounding, tininess, NaN, exception, and format rules. Compiler-rt tests must distinguish helper contracts from undefined C expressions such as signed `INT_MIN / -1`.

- **MEDIUM — §3: application suites are conditional.** LuaJIT lacks uniform ports; `jit.status()` proves enablement, not trace execution. Require evidence of compiled traces. CPython, SQLite, and OpenSSL need pinned builds, dependencies, and explicit exclusions; `speedtest1` alone is insufficient. lmbench completion needs deadlines and output sanity checks. Bootstrap belongs in an explicitly supported release profile.

- **CRITICAL — P3: concurrency and memory need targeted invariants.** Test Provider A/B COW with shared aliases, concurrent `ftruncate`, EOF faults, and translated-page invalidation. Exercise all six `tgkill` quiescence steps, acknowledgment ordering, blocked/exiting threads, and Soft-TLB invalidation before resume. Two-thread activity alone proves little.

- **HIGH — P3–P4: deepen state recovery; shrink smoke.** Inject signals in delay/annulled slots and cached GPR/FPR/window regions; verify precise restart state. Relocate AOT across ASLR, `fork`, `execve`, and `dlopen`, including stale identities. Test Darwin 16 KiB host pages containing independently protected guest 4 KiB/8 KiB pages, straddling accesses, partial unmaps, and COW. Keep smoke deterministic: CRCs plus bounded execution, signal, memory, and loader sentinels. Put broad matrices nightly and randomized, exhaustive, long-duration workloads weekly.
