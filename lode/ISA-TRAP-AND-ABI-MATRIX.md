# `rt-series` 11-Architecture ISA, Trap, Syscall, and Signal Matrix

This reference matrix pins the architectural parameters, ELF identifiers, endianness, pointer vs. register widths, `TASK_SIZE` (`exclusive_limit`), register conventions, condition codes, delay-slot semantics, TLS mechanisms, atomic primitives, Linux syscall conventions, signal frame structures, and supported `libc` sysroots across all 11 foreign guest targets in `rt-series`.

Evidence tags: `[F]` verified repository/Linux UAPI fact, `[I]` inference, `[H]` hypothesis, `[U]` pre-experiment target parameter to be cross-checked by Phase E `offsetof` probes.
