## 4. Non-Negotiable Technical & Workflow Invariants
- **Curated C11**: `-std=c11 -Wall -Wextra -Werror=vla -pedantic`. No VLAs, no Annex K (`*_s`), no `<threads.h>`, no `_Generic`, no `sprintf`/`strcpy`/`strcat`.
- **Zero Dependencies & Static-PIE**: Every translator builds as a static-PIE `aarch64-unknown-linux-musl` binary (`-static-pie -fPIE -Wl,-z,max-page-size=4096`). Host register `x18` is permanently reserved.
- **Copy-First Substrate (`D3`)**: Class-A 32-bit translators (`mips32rt`, `ppc32rt`, `sparc32rt`) copy `src/rt32/` from the Wave-1-cleaned `a32rt`/`i686rt`. Class-B 64-bit translators (`loongarch64rt`, `ppc64rt`, `mips64rt`, `sparc64rt`) copy `src/rt64/` from the Wave-1/2-cleaned `rvrt` using the explicit source-to-destination map in `SPEC.md` §1.3. Never extract a cross-repo shared library.
- **Exclusive File Ownership**: No two concurrent worker lanes in the same sub-wave may write to the same file. Frozen headers and `Makefile`s are strictly read-only to worker lanes.
- **Escalation Rule**: A worker lane stops and escalates to the Coordinator if (1) its acceptance check fails twice, (2) it needs any change to a frozen header or unowned file, or (3) the spec/card is ambiguous.
- **Process & Container Bounds**: Wrap every complete build-and-test command group, container, QEMU, Lima, and `hl` command in `timeout --kill-after=30s <sec> bash -lc "..."`. Name every container uniquely (`--name`) and verify removal (`docker ps -a`) on exit.
- **Git & Commit Hygiene**: Never push (`git push` is forbidden). Use `Moritz Angermann <moritz@zw3rk.com>` as author. Never mention any AI agent or model in commit messages, trailers, or comments. Never bulk-delete sibling worktrees without a content-equivalence (`git cherry`) and dirty/untracked audit plus user approval.
