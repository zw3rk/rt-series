# Waves 4 & 5 — Class-B 64-Bit Full-Address-Space Translators (`loongarch64rt`, `ppc64rt`, `mips64rt`, `sparc64rt`) (Muse Spark Task Cards)

Parent specification: [`../../SPEC.md`](../../SPEC.md) §5  
Parent plan: [`../../PLAN.md`](../../PLAN.md) §3.4  
Host contract: [`../HOST-CONTRACT.md`](../HOST-CONTRACT.md)

All four Class-B 64-bit translators reuse `rvrt`'s full-address-space runtime substrate copied from the Wave-1/2-clean `../rvrt` into `src/rt64/` during Phase 0 (`L0a`) using the frozen source-to-destination map and adaptation seam contract in [`SPEC.md` §1.3](../../SPEC.md):
- `../rvrt/src/linux/space.{c,h} -> src/rt64/rt64_space.{c,h}` (parameterized on `exclusive_limit`),
- `../rvrt/src/linux/memory.{c,h} -> src/rt64/rt64_memory.{c,h}` (preserving byte-granular `brk` and per-syscall `mmap`/`mprotect`/`munmap`/`mremap` validation),
- `../rvrt/src/runtime/family*.{c,h} -> src/rt64/rt64_family*.{c,h}`,
- `../rvrt/src/runtime/file_caps.{c,h} -> src/rt64/rt64_file_caps.{c,h}`,
- `../rvrt/src/runtime/scheduler.{c,h} -> src/rt64/rt64_scheduler.{c,h}`,
- `../rvrt/src/runtime/native_signal.{c,h} -> src/rt64/rt64_native_signal.{c,h}`,
- `../rvrt/src/runtime/safe_syscall_a64.S -> src/rt64/rt64_safe_syscall_a64.S`,
- `../rvrt/src/runtime/exec_state.{c,h} -> src/rt64/rt64_exec_state.{c,h}`,
- `../rvrt/src/runtime/aot_cache.{c,h}` & `../rvrt/src/aot/* -> src/rt64/rt64_aot*.{c,h}`.

All four repositories follow the standardized 9-phase Coordinator + Worker-Lane DAG (`Phase E` -> `Phase 0` -> `Phase 1` -> `Phase 2` -> `Phase 3` (FPU & SIMD) -> `Phase 4` (Signals, Threads, Futex & Process Lifecycle) -> `Phase 5` (Dynamic Linking `PT_INTERP`, BusyBox & Target `libc` Matrix) -> `Phase 6` (`hyper-linux` Integration) -> `Phase 7` (Hardening `H1..H4`)), with Phase-gated `AT_HWCAP`/`CPUCFG` advertising (`SPEC.md` §1.4) and independent `qemu-<arch>` ground-truth oracle comparison at every `RC1`–`RC6` gate.
