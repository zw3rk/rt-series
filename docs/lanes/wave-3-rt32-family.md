# Wave 3 — Class-A 32-Bit 4 GiB-Window Translators (`mips32rt`, `ppc32rt`, `sparc32rt`) (Muse Spark Task Cards)

Parent specification: [`../../SPEC.md`](../../SPEC.md) §4  
Parent plan: [`../../PLAN.md`](../../PLAN.md) §3.3  
Host contract: [`../HOST-CONTRACT.md`](../HOST-CONTRACT.md)

All three Wave 3 repositories (`../mips32rt`, `../ppc32rt`, `../sparc32rt`) use the standardized 9-phase Coordinator + Worker-Lane DAG (`Phase E` -> `Phase 0` -> `Phase 1` -> `Phase 2` -> `Phase 3` -> `Phase 4` -> `Phase 5` -> `Phase 6` -> `Phase 7`):
- **Phase 2** combines static-libc syscalls with the base integer DBT (`tools/difftest.sh` + `qemu-<arch>` ground-truth oracle) and advertises **only integer `AT_HWCAP` bits** (`SPEC.md` §1.4).
- **Phase 3** implements **FPU & SIMD / APU (`interp` + `dbt`)** and enables FPU/SIMD `AT_HWCAP` bits *before* **Phase 4** (Signals, Threads, Futex & Process Lifecycle) and **Phase 5** (Dynamic Linking `PT_INTERP`, BusyBox & Target `libc` Matrix), because `rt_sigframe` save/restore and `ld.so` / `printf` / `strtod` require working FPU/SIMD state.
- Every `RC1`–`RC6` gate wraps its command group in `timeout --kill-after=30s <sec> bash -lc "..."` and compares stdout + exit status against `qemu-<arch>` ground-truth in addition to `interp == dbt`.
