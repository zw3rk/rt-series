## 2. Shared Architectural & Host-Contract Capabilities

| Capability Dimension | Class A — 32-Bit Fixed 4 GiB Window (`a32rt`, `i686rt`, `mips32rt`, `ppc32rt`, `sparc32rt`) | Class B — 64-Bit Full Address Space (`rvrt`, `loongarch64rt`, `ppc64rt`, `mips64rt`, `sparc64rt`) |
|---|---|---|
| **Guest Address Translation** | Parametric 4 GiB window `[G, G + 4 GiB)` held in `x20` (`xG`); 32-bit addresses wrap in `W` registers before `[x20, wAddr, uxtw]` | Sparse software radix page table (`rv_space` / `rt64` 4 KiB pages) over full 40-bit (`mips64rt` N64) or 47-bit (`rvrt`, `loongarch64rt`, `ppc64rt`, `sparc64rt`) Guest VA |
| **`hyper-linux` Host Contract** | `/dev/a32host` (`include/a32host.h`, `A32H_ABI 1.0/1.1`), `G = 0x1_0000_0000` (4 GiB offset mode), `A32H_CAP_ICACHE_TRAP_IALLU` | `HL_MEMORY_POLICY_RVRT`, 1 GiB shared arena (`rvrt_shared`), `hyper-linux-apfs-acl-v1` AOT cache authority, `hl_translators[]` auto-dispatch |
| **AArch64 Register Discipline** | `x18` permanently reserved (macOS / platform TLS); `x20` = `xG` window base; `x19` = CPU context pointer | `x18` permanently reserved; `x19` = CPU context pointer; guest addresses never truncated to 32 bits |
| **W^X & Self-Modifying Code** | Guest data pages mapped `PROT_READ \| PROT_WRITE` only; JIT emits into RW staging, flips to `PROT_READ \| PROT_EXEC`, flushes I-cache, and invalidates translated blocks on `mprotect`/`mmap`/ISA cache-flush instructions | Guest pages never mapped `PROT_EXEC` on host; DBT code arena enforces W^X and invalidates translated blocks on guest writes, `mprotect`/`munmap`, or ISA barrier (`ibar`/`synci`/`icbi`/`flush`) |
| **Dual-Engine Lockstep Oracle (`--difftest`)** | Supported across `i686rt`, `mips32rt`, `ppc32rt`, `sparc32rt` (runs `--interp` and `--dbt` in lockstep, verifying architectural GPR/FPR/PC/flag state at every block/instruction boundary) | Supported across `loongarch64rt`, `ppc64rt`, `mips64rt`, `sparc64rt` (verifies 64-bit GPRs, FPRs/vectors, condition flags, and PC/NPC with 0 divergences) |
| **Toolchain & Binary Footprint** | Curated C11 (`-std=c11 -Werror=vla -pedantic -Wall -Wextra`), zero external runtime dependencies, linked `-static-pie -fPIE` with `aarch64-unknown-linux-musl-gcc` | Curated C11 (`-std=c11 -Werror=vla -pedantic -Wall -Wextra`), zero external runtime dependencies, linked `-static-pie -fPIE` with `aarch64-unknown-linux-musl-gcc` |
